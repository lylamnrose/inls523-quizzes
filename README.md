# INLS 523 Practice Quiz Series

This project is a set of interactive practice quizzes built to reinforce core database concepts (SQL queries, schema reasoning, aggregation, and relational design).

## What this is

* Three standalone quiz pages connected into a simple multi-page site
* Built to simulate exam-style questions and reinforce learning through interaction
* Designed for clarity, speed, and usability

## How it was built

This project was created using a combination of:

* Basic HTML/CSS structure and manual edits (navigation, file organization, deployment)
* AI-assisted development to rapidly generate and iterate on layout, styling, and quiz logic

I used AI as a tool to move from idea → working product quickly, while focusing my effort on:

* Structuring the experience
* Validating functionality
* Connecting and deploying the final product

## What I learned

* How to take a concept and turn it into a working web project
* How to organize and deploy a multi-page site using GitHub Pages
* How to use AI effectively as a development partner rather than a replacement
